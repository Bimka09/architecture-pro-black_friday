## **Решение**

### Orders

```json lines
{
  "_id": ObjectId,
  "user_id": ObjectId,
  "created_at": Date,
  "items": [
    {
      "product_id": ObjectId,
      "price": Number,
      "quantity": Number
    }
  ],
  "status": String,
  "total_price": Number,
  "geo_zone": String
}
```

#### Шардирование

Shard key: user_id

Стратегия: Hash-based sharding

Обоснование: Заказы каждого пользователя создаются на соответствующем шарде, распределяясь равномерно. Таким образом операции:
1) Быстрое создание заказов с одновременным списанием остатков
2) Поиск истории заказов конкретного пользователя
3) Отображение статуса заказа
будут выполняться за минимальное время.

Риск замедления: Возможен перекос, так как пользователи могут переставать пользоваться сервисом, а актвиные перегрузят шард. 

### Products

```json lines
{
  "_id": ObjectId,
  "name": String,
  "category": String,
  "price": Number,
  "remaining_count": {
    "geo_zone": String,
    "count": Number,
  },
  "params": {
    "color": String,
    "size": String,
  }
}
```

#### Шардирование

Shard key: category

Стратегия: Hash-based sharding

Обоснование: Документы будут чаще всего запрашиваться по категорям. Данное расспредление позволит сохранить быстрые обновления остатков, а так же чтения описания продукта, так как операции внутри шарда по id с соответствующей категорией будут оставаться быстрыми.

Риск замедления: Если внутри катеории цены на товары несбалансированы, и в рамках запроса придется ходить на разые шарды.

### Carts

```json lines
{
  "_id": ObjectId,
  "user_id": String,
  "session_id": String,
  "items": [
    {
      "product_id": ObjectId,
      "quantity": Number
    }
  ],
  "status": String,
  "created_at": Date,
  "updated_at": Date,
  "expires_at": Date
}
```

#### Шардирование

Shard key: user_id

Стратегия: Hash-based sharding

Обоснование: Так как шардировать зазазы решили по user_id, то аналогичная стратегия щардирования в корзинах высокую локальность данных. Также это позволдит также быстро продолжать справляться с запросами поиска по user_id.

Риск замедления: Резкий рост гостевых корзин привидет к переполнению шарда. Поиск гостевой корзины потребует опроса всех шардов.
